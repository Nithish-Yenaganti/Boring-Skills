# One-Page Resume Skill

This repository contains a Codex skill for creating or revising LaTeX resumes that compile to exactly one polished, full page.

## Purpose

The skill guides Codex to produce a dense, professional, ATS-friendly LaTeX resume without leaving large unused space or spilling onto a second page.

## Key Constraints

- The resume must compile to exactly one PDF page.
- The layout should look intentionally full, not like a half-page resume.
- Experience and project sections must stay source-grounded.
- Codex may rewrite, tighten, reorganize, and enhance provided facts, but must not invent employers, projects, tools, metrics, outcomes, dates, titles, or responsibilities.
- Final output should include validation details such as compile status, page count, and any visual inspection performed.

## Main File

- `SKILL.md` contains the skill metadata and operating instructions.
